# SDF Cafe Billing System

Complete Node.js/Express and PostgreSQL Billing & POS Application.

## Getting Started

1. Ensure PostgreSQL 17 is running locally with database `cafe.billing` on server `SDF`.
2. Update database credentials in `db.js`.
3. Run `npm install` to install dependencies.
4. Run `npm start` to run the application on `http://localhost:3000`.
